## Abstract

ForgeOS is an Operating Systems and Systems Programming project developed
in a Linux environment using C. The project demonstrates core operating
system concepts through a user-space Unix-style shell called Shellforge
and a kernel-space component called NanoKernel. Shellforge is progressively
developed to support command execution, process management, parsing,
pipelines, I/O redirection, background jobs, job control, and signal
handling.
